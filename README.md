# Universal Gr\"obner Bases of Universal Multiview Ideals

This repository contains all Macaulay2 code used for calculations in the paper *Universal Gröbner Bases of (Universal) Multiview Ideals* (T. Duff, J. Kendrick, and R. Thomas). There are four files:
1. `focals-generation.m2`
2. `focals-n4.m2`
3. `thm1-1-base-case.m2`
4. `thm1-2-base-case.m2`

## `focals-generation.m2`
This file contains code that may be used to generate bi/tri/quadrifocals for the multiview ideal associated to $n$ cameras for any $n.$ The focals for the $n=4$ case are stored in the file `focals-n4.m2`.

## `thm1-1-base-case.m2` and `thm1-2-base-case.m2`
These files contains calculations showing that our Theorems 1.1 and 1.2 hold in the base case of $n=4.$ In particular, we show that no polynomial in the ideal generated by the bi/tri/quadrifocals has support in a facet of the simplicial complexes $\Delta_4$ and $\tilde\Delta_4.$
